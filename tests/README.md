# Test sources

- `cdp/`: DevTools Protocol probes for sites, security state, profiles, extensions, PDFs, downloads, modern web APIs, YouTube codecs, sustained media statistics and interactions.
- `fixtures/`: deterministic local HTTP/media/filter test servers.
- `native/`: Windows 2000 source probes for audio-device enumeration, Chromium-style waveOut behavior, waits and hardware inventory.

No personal profiles, credentials, VM disks, screenshots, logs, captured traffic, crash dumps or compiled test executables are committed. Final results are summarized in `docs/TESTING.md`.
